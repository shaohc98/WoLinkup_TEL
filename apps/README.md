# 运行应用

`apps/` 只包含可部署的运行单元。订单、价格、履约等规则位于 `modules/`，外部系统调用位于 `integrations/`。

| 应用                 | 用户与职责                                       | 首期形态                  |
| -------------------- | ------------------------------------------------ | ------------------------- |
| `international-web`  | 国际消费者；多语言、多币种展示和更多支付方式     | Next.js 响应式 Web        |
| `china-h5`           | 中国大陆消费者；人民币展示，微信/支付宝/余额入口 | Next.js H5；小程序列入 P2 |
| `operations-console` | 运营、客服、供应商、财务、风控和审计岗位         | Next.js 桌面管理台        |
| `tel-api`            | REST `/api/v1`、认证授权、用例编排、Webhook 入口 | NestJS 进程               |
| `tel-worker`         | Outbox、pg-boss、供应商提交/查询、退款与对账任务 | NestJS worker 进程        |

两个消费者站共享业务能力与交易流程，但保留各自的页面、内容、支付展示和合规体验，不通过大量条件分支合并成一个前端应用。

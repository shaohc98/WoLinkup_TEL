# 建设路线图

状态：Draft。具体日期取决于首发市场、主体资质、供应商和支付合同。

## Phase 0：决策与验证

交付：首发国家/运营商、经营主体与资金流、支付/供应商尽调、主数据来源、合规清单、SLO 和单位经济模型。

退出标准：至少一个支付沙箱和两个充值供应商沙箱可联调；错误码、回调、幂等与结算规则有书面契约。

## Phase 1：交易内核

交付：主数据发布、报价、订单、精确金额、支付、供应商适配器、路由、充值 worker、双分录账本、outbox、基础监控。

退出标准：自动化测试覆盖成功、失败、超时未知、重复回调、崩溃恢复和自动退款；不存在手工改库流程。

## Phase 2：MVP 渠道

交付：中国大陆端、国际站、运营后台核心页面、订单查询、客服工单、内容协议、通知和基础对账。

退出标准：选定市场端到端沙箱验收；运营、客服、财务权限与 runbook 完成演练；安全和合规准入通过。

## Phase 3：试运营

交付：小流量真实交易、供应商余额预警、自动对账、退款闭环、指标基线和客户支持机制。

退出标准：连续观察窗口内无重复扣款/充值和账本不平；成功率、时延、毛利及人工率达到批准阈值。

## Phase 4：规模化

交付：更多国家和支付方式、智能路由、风控、企业 API、多语言、区域部署和灾难恢复。

每新增市场都重复执行供应链、支付、税务、隐私、制裁与客户支持准入，不把技术开关等同于可合法运营。

## 优先级建议

先完成交易正确性、主数据和财务闭环，再扩展营销、积分、Banner 和复杂会员体系。原型中的营销与内容能力可以保留规划，但不应阻塞首个安全可运营的充值闭环。

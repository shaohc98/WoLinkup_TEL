# 完成定义

一个功能只有同时满足以下条件才算完成：

- 需求有明确用户、范围、业务规则、异常路径和验收标准。
- API/事件契约已更新并通过兼容性检查。
- 金额、状态、幂等、权限、PII 和审计影响已评估。
- 单元、集成、契约和必要的端到端测试通过。
- 数据库迁移向前兼容，具备回滚/补偿说明。
- 指标、结构化日志、trace 和关键告警已接入，日志无敏感信息。
- 运维 runbook、客服说明和后台处理能力与功能同步。
- 安全、财务或合规高风险变更获得对应评审。
- 文档与实际行为一致，临时 feature flag 有 owner 和清理日期。
- 发布后验证指标、观察时长和失败回退条件已经定义。

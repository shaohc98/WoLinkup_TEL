# 威胁模型与控制基线

状态：Draft。正式上线前需由安全、法务和支付合规负责人评审。

## 高价值资产

- 手机号、客户身份、同意记录、订单和客服内容。
- 支付令牌、退款权限、余额账户和账本。
- 供应商 API 密钥、签名材料、IP 白名单和余额。
- 管理员身份、角色权限、审计日志和配置发布权。
- 价格、汇率、路由策略和主数据发布权限。

## 信任边界

公网客户端、CDN/WAF、API gateway、内部服务、worker、数据库/缓存、支付机构、充值供应商和运营后台分别构成独立信任边界。任何跨边界请求都需要认证、授权、输入验证、超时和审计，不因“内网”而默认可信。

## 主要威胁

| 威胁            | 典型影响                 | 必需控制                                          |
| --------------- | ------------------------ | ------------------------------------------------- |
| 重放/重复请求   | 重复扣款或重复充值       | 幂等键、请求哈希、唯一约束、回调事件去重          |
| 回调伪造        | 虚假支付或充值成功       | 原始 body 验签、时间窗、nonce、来源校验、密钥轮换 |
| 管理员越权      | 修改价格、退款、泄露数据 | MFA、RBAC/ABAC、职责分离、二次审批、全量审计      |
| 凭证泄漏        | 资金和供应链损失         | secret manager、短期凭证、禁日志、轮换和泄漏扫描  |
| 号码枚举        | 用户隐私泄漏             | 统一响应、速率限制、风险评分、脱敏查询            |
| 参数篡改        | 低价购买或错误面额       | 服务端引用报价快照，拒绝客户端传最终价格          |
| 供应商故障/恶意 | 订单丢失或虚假状态       | 适配器隔离、健康检查、对账、限额、人工复核        |
| SSRF/文件攻击   | 内网访问或恶意载荷       | 出站 allowlist、文件类型/大小检查、隔离解析       |
| 日志泄漏        | PII/密钥扩散             | 结构化白名单日志、集中脱敏、受限保留与访问        |
| 账务篡改        | 余额不实                 | 不可变分录、借贷平衡、职责分离、日终核对          |

## 身份与授权

- 消费者会话使用短期访问令牌与安全刷新机制；高风险操作重新认证。
- 后台强制企业身份源和 MFA；服务端按资源、动作、数据范围授权。
- 服务间使用独立工作负载身份，禁止共享管理员令牌。
- 财务退款、人工标记成功、密钥变更和大额余额调整执行四眼审批。

## 数据保护

- 传输使用 TLS；静态存储使用平台加密，手机号等高敏字段应用层信封加密。
- 可搜索字段保存带独立 pepper 的稳定哈希；展示值单独脱敏保存。
- 密钥与数据分域，密钥轮换不要求重写业务历史。
- 按地区和业务目的定义保留周期，到期删除或不可逆匿名化。
- 分析、测试和客服工具只接收最小字段，不使用生产数据复制。

## 合规待办

实际经营主体、目标市场、资金流和数据流未确定前，不能对牌照、跨境支付、税务、发票、制裁筛查、数据跨境或隐私合规作最终结论。每个上线国家必须形成专项清单并由专业顾问确认。

# WoLinkup TEL 文档中心

## 文档权威顺序

1. 四份 V1.0 正式说明书及其后续受控版本。
2. 已接受的 ADR 和机器可验证契约。
3. 本仓库的实施说明、草案和产品原型。

出现冲突时必须记录差异并通过 ADR 或正式文档修订解决，不能只在代码或会议中改变关键业务约束。

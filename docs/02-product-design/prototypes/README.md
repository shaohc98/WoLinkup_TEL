两份 HTML 均为无外部依赖的单文件交互原型，可直接在浏览器打开。它们用于需求追溯和交互讨论，不作为生产代码或生产数据源。

## 管理规则

- `legacy/` 是不可变输入。任何修改都创建新版本，不覆盖原始文件。
- 正式原型按产品端和版本号独立归档；已发布版本不可覆盖，更新时创建新版本目录。
- 当前版本的认定以本页“当前基线”表为准，不通过覆盖文件表达版本升级。
- 原型出现的密钥、账号、手机号、域名和汇率全部按演示数据处理。
- 原型文案中的协议和隐私政策必须经法务按实际经营主体与服务地区审核。
- 原型需求进入研发前，必须形成需求编号、验收标准和接口/事件契约。
- 国家号码规则、运营商状态和产品面额需要来源、有效期、审核人和变更记录。

## 校验信息

历史文件校验值记录在 `legacy/SHA256SUMS`，正式版本在各版本目录维护独立的 `SHA256SUMS`。可运行 `pnpm verify` 检查归档是否被意外修改。

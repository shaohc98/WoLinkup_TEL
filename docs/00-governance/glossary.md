# 术语表

| 术语                | 定义                                           |
| ------------------- | ---------------------------------------------- |
| Top-up              | 向预付费移动号码充值话费或余额                 |
| Face Value          | 最终进入手机号账户的当地币种面值               |
| Sale Price          | 客户购买商品的基础售价，不一定等于面值折算     |
| Payable Amount      | 服务费、优惠等计算后客户实际支付金额           |
| Quote               | 有有效期的完整价格与商品快照                   |
| Topup Order         | 面向客户的一次充值购买                         |
| Fulfillment Attempt | 向某一个供应商 SKU 发起的一次履约尝试          |
| Supplier SKU        | 供应商对某个运营商面额/范围产品的外部标识      |
| Route               | 当前订单可选择的供应商 SKU 通道                |
| Unknown             | 请求结果无法确认，既不能视为成功也不能视为失败 |
| Idempotency         | 多次执行同一意图只产生一次业务效果             |
| Outbox              | 与业务事务一起保存、之后可靠发布的事件记录     |
| Ledger              | 由不可变借贷分录组成的资金事实系统             |
| Reconciliation      | 将内部交易/账本与支付或供应商账单进行核对      |
| Settlement          | 与支付渠道或供应商实际清算资金的过程           |
| E.164               | 国际公共电话编号格式标准                       |
| PII                 | 可识别或关联自然人的个人信息                   |

# 数据库

PostgreSQL 18 是 TEL 首期唯一权威数据存储，并承载 Outbox/Inbox 和 pg-boss 持久任务。业务表按领域 schema 隔离；模块只能写入自己拥有的表，跨模块读取通过公开查询接口或受控只读投影完成。

- `migrations/`：不可变、按序执行的结构迁移。
- `seeds/`：仅用于本地与测试的确定性合成数据。
- `sql/`：人工诊断和受控修复脚本，必须说明只读性、事务和回滚方式。

金额使用 PostgreSQL `numeric` 或经评审的最小单位整数，时间保存为 UTC `timestamptz`。关键幂等、唯一性和并发约束必须落到数据库，而非只依靠应用判断。

# ADR 0002：不可变双分录账本

状态：Accepted

## 背景

平台同时处理客户收款、余额、退款、支付渠道清算、供应商采购、汇兑和收入。只维护可变余额与流水说明无法可靠重建历史，也难以发现资金不平。

## 决策

所有资金变化使用不可变凭证和分录表达。每个凭证按币种借贷平衡；错误通过冲正凭证修复。展示余额是分录聚合或可重建投影。交易金额以最小货币单位整数和币种 exponent 保存。

## 结果

- 可以追溯任一余额和重建财务报告。
- 退款、拒付、优惠和汇兑差额有明确会计语义。
- 写入路径更严格，需要科目表、凭证模板、日终检查和财务评审。
- 数据库约束之外仍需应用校验与持续不平衡监控。
